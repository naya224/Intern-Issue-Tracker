# Intern-Issue-Tracker
An Android-based Intern Issue Tracking System developed using Kotlin, Jetpack Compose, and Firebase. The application allows interns to report and track issues while administrators can manage tickets, update statuses, and communicate through comments and replies.
# Intern Issue Tracker

## Project Overview
Intern Issue Tracker is an Android application designed to help interns report issues and allow administrators to manage and track them efficiently.

## Features
- User Registration and Login
- Admin and Intern Roles
- Report New Issues
- View and Track Tickets
- Update Issue Status
- Status History
- Comments and Replies
- Search and Filter Issues
- Firebase Real-Time Data Updates

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore

## User Roles
**Admin:** View all reported issues, manage tickets, update statuses, and respond through comments.

**Intern:** Register, log in, report issues, view personal tickets, and communicate through comments.

## Purpose
The purpose of this project is to provide an organized platform for reporting, managing, and tracking internship-related issues.
